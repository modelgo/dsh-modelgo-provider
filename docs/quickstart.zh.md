# ModelGo

把 ModelGo 的两个站点接入 DeepSeek Harness 的模型选择器。

## 安装后只需要一步：填写密钥

往下滚动本页，在这段说明之后有两张卡片：**ModelGo（modelgo.com）** 和 **ModelGo（modelgo.ai）**。在你使用的站点那张卡片里粘贴密钥，点**验证并保存**。

同样的输入框也在**设置 → 模型**里，两处填哪一处都可以。

保存后，回到对话框，点输入框右下角的模型名称，就能在列表里看到 ModelGo 这一组模型。不需要重启。

## 密钥从哪里来

| 你使用的站点 | 在哪里创建密钥 | 密钥填在哪张卡片 |
|---|---|---|
| modelgo.com | 登录 modelgo.com 的控制台创建 | ModelGo（modelgo.com） |
| modelgo.ai | 登录 modelgo.ai 的控制台创建 | ModelGo（modelgo.ai） |

两个站点的账号和密钥互不通用。只需要填你使用的那个站点，另一个留空即可；没有密钥的站点不会显示模型。

密钥以 `mgk_` 开头。保存前插件会先向站点验证，填错了或者填成另一个站点的密钥，会当场提示，不会保存。

## 常见情况

| 现象 | 怎么办 |
|---|---|
| 模型选择器里没有 ModelGo | 还没有保存密钥。回到本页或「设置 → 模型」填写 |
| 提示站点不接受这个密钥 | 确认密钥没有被删除，并且填在了对应站点的卡片里 |
| 缺少某个模型 | 这把密钥在 ModelGo 控制台里没有该模型的权限，或者它不是对话模型 |
| 想换一把密钥 | 直接粘贴新密钥并保存，会替换旧的 |

## 密钥存在哪里

密钥只保存在本机的 DSH 凭据库里，不会写进配置文件，保存后也不会再显示。

更多配置项见[项目主页](https://github.com/modelgo/dsh-modelgo-provider#readme)。
